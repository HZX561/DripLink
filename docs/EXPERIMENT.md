# 当前实验与指标口径

本文记录维护者本地实验。涉及的权重、完整数据清单、逐图预测和本机维护记录不随源码仓库发布；公开汇总见 `reports/metrics.json`，资产准备见 [复现说明](REPRODUCIBILITY.md)。

## 模型及数据来源

- 数据来源：WMeter5K，参考项目 https://github.com/ZZZHANG-jx/WMeter-Reader 。保留原始下载包 `data/raw/WMeter5K_source.zip`，当前模型没有使用作者发布的 im.pkl/tr.pkl 权重。
- 当前检测器：YOLO11n Pose，11 类（10 个倍率位置及历史 wheel 类），每个区域 4 个有序角点，输入 512。沿用混合表阶段训练完成的 26 轮检测器；当前推理只使用全指针区域。保留 wheel 类索引是为了兼容现有权重，不代表支持混合型读数。
- 当前读数网络：64×64 灰度表盘裁剪，CNN 局部识别及 2 层 Transformer 上下文纠正，共 **953,194** 个参数，无字轮分支。位序为 10^5 至 10^-4 m³。当前 baseline 来源于此前读数网络的指针与上下文参数，继承此前训练历史，并非从零独立训练的新模型。
- 后续进行了 25 轮全指针微调，单独端到端验证未超过 baseline：整数准确率同为 570/607，完整读数 477/607，低于 baseline 的 480/607。因此保留 baseline，未凭测试集选择此候选。失败实验的验证结果和训练记录位于 `reports/training/`。

原始 5000 张按当前工作规则分为全指针 3817、字轮混合 1183；这是本项目的分类口径，包含对歧义图片的人工检查，不是作者提供的类型字段。清洗后全指针 3780、混合 1153。当前工作目录仅展开 3780 张全指针图，其他原始图片仍在原始下载包中。

## 端到端准确率

| 指标 | 验证集 607 张 | 历史测试集 572 张 |
|---|---:|---:|
| 有读数输出 | 607/607 | 572/572 |
| 整数 m³ 完全正确 | 570/607，93.90% | 518/572，90.56% |
| 完整读数完全正确 | 480/607，79.08% | 452/572，79.02% |
| MAE，m³ | 242.7997 | 2104.5677 |
| 绝对误差中位数，m³ | 0 | 0 |

整数准确率按小数点前全部数字完全匹配，完整读数按统一 4 位小数匹配（不足补零）。分母包含全部图片，识别失败计错。MAE 针对返回读数，必须同时看覆盖率。少量高倍率错误会显著拉高 MAE，仍是需要改进的实际识别问题。

读数网络输出的只是预测；现有评估真值来自数据集提供的读数标签，尚未完成团队逐图复核。原旧项目 100 张照片及其几何标注不参与当前模型训练，也不作为当前人工真值。

测试集在此前混合表实验及预处理修复中曾被评估/检查，因此目前报告的是**内部历史复测**。`models/selection.json` 记录当前候选选择只看验证集，不抵消更早的测试查看历史。尚无新的实体独立数据，不能由当前分数推出跨地点、跨设备的实际泛化水平。

## 本次代码整理的验证

选定检测器和读数权重 SHA256 均未改变。迁移后重新评估全部 607 张验证图，自动上下文、自动独立位、标注区域上下文、标注区域独立位四条路径的逐图读数均与原结果一致。证据见 `reports/maintenance/equivalence.json` 和 `reports/verification/refactor_validation/`。

另在新入口上执行 1 轮 GPU 训练以验证训练过程，产物仅用于流程检查，不参与模型选择，不替换当前模型。固定环境、种子和数据支持实验复查；CUDA 池化反向传播存在非确定性，不能承诺不同训练运行的权重逐比特一致。
