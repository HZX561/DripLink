# 文件管理约定与本次清理

本说明同时记录本地研究工作区。GitHub 仓库只发布源码、文档、空采集模板和汇总指标；下文的照片、标注、权重、备份及本机报告由 `.gitignore` 保留在本地。可公开复现的范围见 [复现说明](REPRODUCIBILITY.md)。

## 保留范围

当前只保留全指针水表的识别、读数网络/检测器微调、验证选优、历史测试复测、独立数据采集评估及其必要产物。统一从根目录 `README.md` 进入，核心 Python 模块位于 `watermeter/`。

`models/detector.pt`、`models/reader.pt`、`models/selection.json` 是当前模型，不要随意覆盖。训练使用新实验名写入 `runs/`，评估使用新目录写入 `reports/`。是否替换模型只能依据验证集，完整读数准确率用于整数准确率相同时的比较。

数据分为原始包 `data/raw/`、当前原图 `data/images/`、冻结标注及划分 `data/manifest.json`、可重建裁剪 `data/cache/`。原始包和冻结清单不直接修改。移动整个项目后当前代码仍从项目根目录定位数据；重新生成的 YOLO 训练列表是本机路径，换电脑时用 `train_detector.py --name 任意新名称 --prepare-only` 重建。

历史评估、旧模型选优和来源记录中的绝对路径按原样保留，仅作实验出处；运行入口使用新的相对模型路径及数据目录，不依赖那些旧文件。

## 已移除的内容

- 原 100 张项目的训练、指针几何算法、标注转换、旧 PCK 评估、核对网页和旧测试代码。
- Flask 页面、数据库、网页启动脚本，以及对应 8 项不再使用的 Web 依赖声明；不再保留部署流程。
- 字轮混合模型分支、ResNet/相位等未采用候选分支及其权重、未被采用的 fine-tune 权重。
- 旧 `data_wmeter5k`、`data_wmeter_pointer` 和 `external_data` 展开目录，重复原图、轮盘空缓存、过时的 YOLO 标签和路径配置。
- 旧 `runs/` 和 `output/` 中的实验权重、网页、临时裁剪、重复核对导出；必要的训练记录、选优结果和历史测试结果已归入 `models/provenance/` 与 `reports/`。
- 过期说明文件、原模型下载缓存、PDF 临时文件和旧字节码缓存。

现有 CPU/GPU 虚拟环境保留，避免破坏已验证的运行环境。锁文件只要求当前核心依赖；旧环境内残留的额外 Web 包不参与运行，也没有主动卸载。

## 原始资料备份

- `data/raw/WMeter5K_source.zip`：完整原始下载包，包含当前不展开使用的混合表图片及作者原标注，可追溯来源。
- `data/raw/legacy_originals.zip`：原 100 张项目的原图、人工几何标注、标签及人工核对资料，合并为一份备份，已校验 ZIP CRC。保留原始资料是为了避免丢失人工工作；旧训练、网页及中间产物不在此备份中。

备份只用于资料追溯，不参与当前训练。请不要重新将其展开到项目根目录。日常从 `data/images/` 和 `reports/review/` 查找当前资料。

## 清理后的检查

模型及冻结清单哈希不变、3780 张图片逐张校验；验证集 607 张、4 条解码路径的预测逐张一致；完成 GPU 训练流程检查、CPU 识别及回归测试。维护记录见 `reports/maintenance/`，验证证据位于 `reports/verification/`。

后续仅在 `reports/` 放结果，在 `runs/` 放实验模型；临时测试产生的大权重确认无用途后删除，但保留对应参数、日志和验证结论。
